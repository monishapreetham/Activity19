

## How it works

Implements two input combinational logic AND gate. The circuit takes two digital inputs and inputs them into an AND gate and the resulting output is shown through an LED.

## How to test

Run the simulation by pressing the green play button. Then toggle the top two switches to test various possible combinations and observe the output through if the LED lights up or not. It should light up when both switches are toggled.

## External hardware

Red DIP switch bank for the inputs, and LED which is connected to ground to visualize output.
